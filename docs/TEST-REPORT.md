## 测试中发现并已修复的问题

1. **复习卡片自动翻回正面。** `useSettings()` 每次渲染都返回新对象，导致复习页不断重新加载队列。已改为稳定引用，E2E 3 加了回归检查。
2. **手机端词汇页筛选器占半屏。** 已改为在手机上收进「筛选」按钮。

## 已知问题与限制

- 打包体积约 600 KB（gzip 后 187 KB），首次加载后由 Service Worker 缓存。后续可拆分。
- 自动加 l' 的规则只处理元音开头的词；h 开头的词（l'homme / le héros）需要手动填冠词。
- iPhone 上必须「添加到主屏幕」使用，否则 Safari 可能在 7 天未使用后清除本地数据。设置页已有说明。
- 在 Safari / WebKit 上没有跑自动化测试：这里只有 Chrome 可用。部署后需要在你的 iPhone 上实测一遍。
